## ✦ &nbsp;О проекте

Специально для моей любимой девочки, этот файл для крутости написан )))

<br>

## ✦ &nbsp;Как это выглядит

```
[ Экран 1 ]  Сердце заполняется жидкостью → кнопка «Жмякни»
     ↓
[ Экран 2 ]  Имя + приглашение войти
     ↓
[ Экран 3 ]  Текст с дождём и летящими 💙
     ↓
[ Экран 4 ]  Послания раскрываются по одному при касании
     ↓
[ Экран 5 ]  Финал — фонтан из сердец снизу вверх
```

<br>

## ✦ &nbsp;Технологии

| Что | Зачем |
|---|---|
| `Canvas API` | Звёздное небо + анимация дождя |
| `CSS Custom Properties` | Единая цветовая система |
| `CSS Keyframes` | Все анимации без JS |
| `SVG clipPath` | Жидкое заполнение сердца |
| `Backdrop-filter` | Стеклянные карточки |
| `Cormorant Garamond` | Романтичный дисплейный шрифт |
| `Outfit` | Чистый гротеск для интерфейса |

Никаких зависимостей. Никаких сборщиков. Просто три файла.

## ✦ &nbsp;Запуск

Скачай репозиторий и открой `index.html` в браузере — больше ничего не нужно.

```bash
git clone https://github.com/shalavochkk/Postcard-for-Varya.git
cd Postcard-for-Varya
open index.html
```

Или просто перетащи файл в браузер.

<br>

## ✦ &nbsp;Визуальные детали

- **Звёздное небо** — 120 звёзд мерцают на canvas в реальном времени
- **Аврора** — два синих блоба медленно дышат за карточками
- **Дождь** — 55 капель на отдельном canvas, включается на втором слайде
- **Падающие сердца** — спавнятся сверху, уносятся вниз
- **Финальный фонтан** — 45 элементов взлетают снизу с кубической кривой Безье
- **Glassmorphism** — `backdrop-filter: blur(50px)` + многослойные тени
- **Safe area** — поддержка `env(safe-area-inset-bottom)` для iPhone с чёлкой
